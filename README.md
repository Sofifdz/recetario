# Recetario con Realidad Aumentada

---

## Descripción

Este proyecto consiste en el desarrollo de una aplicación en Unity que utiliza realidad aumentada para visualizar recetas de cocina mediante el reconocimiento de imágenes. A través de la cámara del dispositivo, la aplicación identifica una imagen objetivo y, dependiendo de la imagen detectada, muestra una de las tres recetas disponibles junto con su información correspondiente.

---

## Funcionalidades principales

* Reconocimiento de imágenes mediante la cámara del dispositivo.
* Visualización de recetas utilizando realidad aumentada.
* Identificación de tres imágenes objetivo diferentes.
* Presentación de la receta correspondiente a cada imagen reconocida.
* Interfaz interactiva para la consulta de recetas.

---

## Tecnologías utilizadas

* Unity
* C#
* Vuforia Engine
* Realidad Aumentada (AR)
